# Project Brief: MobileApp

## Обзор проекта

MobileApp — это мобильное приложение на Unity 6 для платформы VR/мобильных устройств, разрабатываемое компанией Sotbifay. Приложение предоставляет комплексный набор функций для взаимодействия пользователей с VR-платформой.

## Основные цели

1. Предоставить удобный мобильный интерфейс для доступа к VR-платформе
2. Обеспечить коммуникацию пользователей через чат с поддержкой SSE
3. Интеграция с партнёрскими сервисами и бонусной системой
4. Предоставление новостной ленты и актуальной информации
5. Поддержка системы туториалов для онбординга новых пользователей

## Ключевые функции

- **Chat** — система обмена сообщениями с поддержкой SSE (Server-Sent Events)
- **News** — новостная лента с загрузкой контента
- **Casino** — интеграция с игровыми сервисами
- **Profile** — управление профилем пользователя
- **WebView** — отображение веб-контента
- **Tutorial** — пошаговая система обучения
- **Bonuses** — система бонусов и наград
- **QR Scanner** — сканирование QR-кодов
- **Dock** — навигационная панель
