## Эволюция проектных решений

### Миграция на Unity 6

Проект мигрировал на Unity 6 (6000.0.58f2) с использованием:
- URP 17.x
- Новая Input System
- Обновлённые пакеты

### Выбор R3 вместо UniRx

R3 выбран как более современная альтернатива UniRx с лучшей производительностью и поддержкой.

### VContainer вместо Zenject

VContainer выбран за:
- Лучшую производительность
- Простой API
- Активную поддержку
