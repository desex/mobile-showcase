# Product Context: MobileApp

## Почему существует этот проект

MobileApp создан для предоставления пользователям мобильного доступа к экосистеме VR-платформы Sotbifay. Приложение решает проблему недоступности ключевых функций платформы без VR-устройств, позволяя пользователям оставаться на связи и управлять своим аккаунтом с мобильных устройств.

## Какие проблемы решает

1. **Доступность** — пользователи могут получать уведомления и сообщения без необходимости использования VR-гарнитуры
2. **Коммуникация** — чат с менеджерами и поддержка через SSE обеспечивает real-time общение
3. **Информированность** — новостная лента держит пользователей в курсе событий платформы
4. **Бонусы и акции** — удобный доступ к бонусной программе и партнёрским предложениям
5. **Онбординг** — система туториалов помогает новым пользователям освоиться

## Как должно работать

### Пользовательский опыт

1. **Первый запуск**
   - Приветственный экран
   - Пошаговый туториал по основным функциям
   - Запрос необходимых разрешений (камера, уведомления)

2. **Главный экран (Home)**
   - Быстрый доступ к основным функциям через Dock
   - Отображение актуальных новостей и бонусов

3. **Чат**
   - Real-time сообщения через SSE
   - Поддержка различных типов сообщений (текст, blackjack-карточки)
   - История сообщений сохраняется локально

4. **Профиль**
   - Управление личной информацией
   - Настройки уведомлений
   - Просмотр статистики

5. **Бонусы**
   - Просмотр доступных бонусов
   - Активация промокодов
   - История бонусов

## Цели пользовательского опыта

- **Быстрота** — мгновенный доступ к ключевым функциям
- **Интуитивность** — понятный интерфейс без лишних действий
- **Надёжность** — стабильная работа даже при плохом соединении
- **Персонализация** — адаптация под предпочтения пользователя
